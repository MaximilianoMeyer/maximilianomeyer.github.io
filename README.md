# Max Meyer — Arcade CRT Portfolio

Portfólio estático compatível com GitHub Pages.

## Career Invaders

- Movimento: `A/D` ou setas esquerda/direita
- Disparo: `Espaço`
- Sair: `Esc`
- Destrua as naves douradas `CAREER` para abrir as experiências de `experiencias.json`.

## Certification Road

- Movimento: setas esquerda/direita
- Acelerar: `Espaço`
- Sair: `Esc`

Para testar localmente:

```bash
python -m http.server 8000
```

Acesse `http://localhost:8000/`.
